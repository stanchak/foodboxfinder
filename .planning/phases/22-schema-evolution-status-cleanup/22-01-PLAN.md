**Implementation approach:** For notes, read the current provider record first to check if notes already has content. If so, append with `\n\n` separator. If null, set directly. Use a helper function:

```typescript
async function appendNote(slug: string, newNote: string) {
  const provider = await prisma.provider.findUnique({
    where: { slug },
    select: { notes: true },
  });
  if (!provider) {
    console.log(`  SKIP: ${slug} not found in database`);
    return;
  }
  const updatedNotes = provider.notes
    ? `${provider.notes}\n\n${newNote}`
    : newNote;
  await prisma.provider.update({
    where: { slug },
    data: { notes: updatedNotes },
  });
  console.log(`  Updated notes for ${slug}`);
}
```
