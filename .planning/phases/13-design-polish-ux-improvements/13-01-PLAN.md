2. **Collapsible/expandable filter groups** — Add a collapsible wrapper around each fieldset's options. Add a `collapsedGroups` state (useState<Set<string>>) tracking which groups are collapsed. Each fieldset legend becomes a button that toggles collapse. Use a chevron icon that rotates when expanded. Initially all groups are expanded (empty set). The pattern:
```tsx
const [collapsedGroups, setCollapsedGroups] = useState<Set<string>>(new Set());

function toggleGroup(group: string) {
  setCollapsedGroups(prev => {
    const next = new Set(prev);
    if (next.has(group)) next.delete(group);
    else next.add(group);
    return next;
  });
}
```
For each fieldset, replace the static `<legend>` with:
```tsx
<legend className="contents">
  <button
    type="button"
    onClick={() => toggleGroup("prep")}
    className="flex w-full items-center justify-between text-sm font-medium text-gray-700 mb-2 focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary-500 focus-visible:ring-offset-2 rounded"
    aria-expanded={!collapsedGroups.has("prep")}
  >
    Prep Style
    <svg ... className={`shrink-0 w-4 h-4 text-gray-400 transition-transform duration-200 ${!collapsedGroups.has("prep") ? "rotate-180" : ""}`} aria-hidden="true">
      <path d="m6 9 6 6 6-6" />
    </svg>
  </button>
</legend>
```
Then wrap the options div with: `{!collapsedGroups.has("prep") && (<div className="space-y-2">...</div>)}`

Apply this pattern to ALL 6 filter groups (Dietary Preferences, Prep Style, Value Tier, Household Fit, Model Type, Geography). Sort select stays as-is (not collapsible).
