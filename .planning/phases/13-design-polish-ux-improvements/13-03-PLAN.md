**AffiliateLink.tsx changes:**

3. **sr-only "(opens in new tab)" text** — In both the compact and primary variants, add a sr-only span inside the `<a>` tag, after the visible text and icon:
```tsx
<span className="sr-only">(opens in new tab)</span>
```
Add this just before the closing `</a>` tag in both the compact variant (after `<ExternalLinkIcon size={14} />` on line ~27) and the primary variant (after `<ExternalLinkIcon size={16} />` on line ~41).

**FaqAccordion.tsx changes:**

4. **Remove non-functional CSS transition** — On the panel div (line ~74), remove the `transition-all duration-200` classes. The `hidden` attribute controls visibility, making CSS transitions non-functional. Change:
```tsx
className={`overflow-hidden transition-all duration-200 ${isOpen ? "pb-4" : "max-h-0"}`}
```
to:
```tsx
className={isOpen ? "pb-4" : ""}
```
Also remove `max-h-0` since the `hidden` attribute already handles hiding. The `overflow-hidden` can also be removed since it was only needed for the (non-functional) height transition.

**Pagination.tsx changes:**

5. **Remove aria-disabled from non-interactive spans** — Remove `aria-disabled="true"` from the disabled Previous span (line ~66) and the disabled Next span (line ~170). The `aria-disabled` attribute is only valid on interactive elements. The `cursor-not-allowed` class and visual styling already communicate the disabled state. Remove just the `aria-disabled="true"` attribute from both spans, keeping everything else.
