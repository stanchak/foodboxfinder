**4. Add new filter sections** in this order within the sidebar:

6. **Model Type** — checkboxes. URL param: `model`. Values from Object.keys(MODEL_TYPE_GROUPS). Labels from `.label` property. Single-select.
7. **Geography** — checkboxes. URL param: `geo`. Values from Object.keys(GEOGRAPHY_GROUPS). Labels from `.label` property. Single-select.

For single-select filters (prep, valueTier, household, model, geo): clicking an already-active option deselects it (toggle behavior). Only one value at a time. Use `updateParams({ [paramKey]: newValue === currentValue ? null : newValue })`.

For multi-select (diet): same comma-separated toggle behavior as existing code.

**5. Change the component props** to remove `activeFilterCount` and instead compute it internally from `useSearchParams()`. Count any non-empty values for: `diet`, `prep`, `valueTier`, `household`, `model`, `geo`. For `diet`, count the number of comma-separated values. For `sort`, don't count it as a "filter" since it's a sort option.

- For single-select filters, renders one chip showing the label
- Clicking X on a chip removes that specific param (for diet, removes that tag from the comma-separated list)
