**Core architecture:**

1. **Provider selection:** Query all providers where `description` contains "see research notes" OR `shortDescription` is null OR `prosJson` is null. This captures both the original 77 JSON-only providers AND the 22 new Phase 23 providers. Skip providers that already have ALL of: real description (not containing "see research notes"), shortDescription, prosJson, consJson, and valueTier set — these are the ~18 hand-crafted providers.

2. **For hand-crafted providers (already have description NOT containing "see research notes"):** Only fill fields that are currently null. Do NOT overwrite existing data. Check each field individually before updating.

3. **Batch processing:** Process providers in batches of 10. Between each batch, wait 5 seconds to respect API rate limits. Between each individual API call within a batch, wait 2 seconds.

4. **xAI API call function:** Create an `async function researchProvider(name: string, website: string, category: string)` that calls the xAI Responses API:

```typescript
async function researchProvider(
  name: string,
  website: string,
  category: string,
): Promise<EnrichmentData | null> {
  const prompt = `Research the food subscription service "${name}" (website: ${website}, category: ${category}).

Return a JSON object with EXACTLY these fields. Be factual — only include information you can verify from the website or reliable sources. If you cannot determine a field, set it to null.

{
  "description": "2-3 factual sentences about what this service offers, who it's for, and what makes it unique. Do NOT use marketing language.",
  "shortDescription": "Under 280 characters. One sentence summarizing the service for a comparison card.",
  "pros": ["3-4 genuine advantages as strings"],
  "cons": ["2-3 honest disadvantages as strings"],
  "valueTier": "One of: BUDGET (under $7/serving or under $50/box), MID ($7-12/serving or $50-100/box), PREMIUM ($12-18/serving or $100-150/box), LUXURY (over $18/serving or over $150/box). Base this on actual pricing from the website.",
  "dietaryTags": ["Array of applicable tags from: VEGAN, VEGETARIAN, PESCATARIAN, KETO, PALEO, GLUTEN_FREE, DAIRY_FREE, NUT_FREE, LOW_CARB, LOW_SODIUM, ORGANIC, HALAL, KOSHER, DIABETIC_FRIENDLY, WHOLE30, MEDITERRANEAN. Only include tags the provider explicitly supports with dedicated menu options or filters."],
  "flexibility": "1-2 sentences about skip/pause/cancel policy. e.g. 'Skip or cancel anytime with no penalty. Changes must be made by Wednesday for the following week's delivery.'",
  "foundedYear": 2015,
  "headquarters": "City, State format e.g. 'New York, NY' or 'Austin, TX'",
  "deliveryAreaDescription": "e.g. 'Contiguous US (48 states)' or 'Select metro areas in California and New York'",
  "householdFit": "Who this is best for, e.g. 'Singles and couples who want convenient healthy meals' or 'Families of 4+ looking for budget-friendly meal kits'",
  "geography": "Only if the provider has geographic limitations, e.g. 'West Coast only' or 'Northeast US'. null if nationwide."
}

IMPORTANT: Return ONLY the JSON object, no markdown formatting, no code blocks, no explanation.`;

  const response = await fetch("https://api.x.ai/v1/responses", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.XAI_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "grok-4-1-fast-reasoning",
      input: [{ role: "user", content: prompt }],
      tools: [{ type: "web_search" }],
      temperature: 0.2,
    }),
  });

  if (!response.ok) {
    console.error(`  API error ${response.status}: ${await response.text()}`);
    return null;
  }

  const data = await response.json();
  // Parse response: output[] -> find type: "message" -> content[] -> find type: "output_text" -> .text
  const messageItem = data.output?.find((item: { type: string }) => item.type === "message");
  const textContent = messageItem?.content?.find((c: { type: string }) => c.type === "output_text");
  const rawText = textContent?.text;

  if (!rawText) {
    console.error(`  No text in API response for ${name}`);
    return null;
  }

  // Strip markdown code fences if present
  const jsonStr = rawText.replace(/^```json?\s*\n?/i, "").replace(/\n?```\s*$/i, "").trim();

  try {
    return JSON.parse(jsonStr) as EnrichmentData;
  } catch (e) {
    console.error(`  Failed to parse JSON for ${name}: ${e}`);
    console.error(`  Raw text: ${rawText.substring(0, 200)}`);
    return null;
  }
}
```

6. **Validation before writing to DB:**
- `description`: Must be non-empty, must NOT contain "see research notes", must be under 2000 chars
- `shortDescription`: Must be under 300 chars (VarChar(300) constraint)
- `pros`: Must be array of 2-5 strings, each under 200 chars
- `cons`: Must be array of 1-4 strings, each under 200 chars
- `valueTier`: Must be one of BUDGET, MID, PREMIUM, LUXURY
- `dietaryTags`: Each must be a valid DietaryTag enum value — validate against the set: VEGAN, VEGETARIAN, PESCATARIAN, KETO, PALEO, GLUTEN_FREE, DAIRY_FREE, NUT_FREE, LOW_CARB, LOW_SODIUM, ORGANIC, HALAL, KOSHER, DIABETIC_FRIENDLY, WHOLE30, MEDITERRANEAN
- `foundedYear`: Must be integer between 1900 and 2026, or null
- `shortDescription` and `description` must not be identical

```typescript
async function updateProvider(
  provider: { id: string; slug: string; description: string; shortDescription: string | null; prosJson: unknown; consJson: unknown; valueTier: string | null },
  data: EnrichmentData,
) {
  const isStub = provider.description.includes("see research notes");
  const updateData: Record<string, unknown> = {};

  // Only update fields that are currently empty/stub
  if (isStub && data.description) updateData.description = data.description;
  if (!provider.shortDescription && data.shortDescription) updateData.shortDescription = data.shortDescription.substring(0, 300);
  if (!provider.prosJson && data.pros) updateData.prosJson = data.pros;
  if (!provider.consJson && data.cons) updateData.consJson = data.cons;
  if (!provider.valueTier && data.valueTier) updateData.valueTier = data.valueTier;
  // ... same pattern for all fields

  if (Object.keys(updateData).length > 0) {
    await prisma.provider.update({
      where: { id: provider.id },
      data: updateData,
    });
  }

  // Handle dietary tags separately (relation table)
  if (data.dietaryTags && data.dietaryTags.length > 0) {
    const VALID_TAGS = new Set([
      "VEGAN", "VEGETARIAN", "PESCATARIAN", "KETO", "PALEO",
      "GLUTEN_FREE", "DAIRY_FREE", "NUT_FREE", "LOW_CARB",
      "LOW_SODIUM", "ORGANIC", "HALAL", "KOSHER",
      "DIABETIC_FRIENDLY", "WHOLE30", "MEDITERRANEAN",
    ]);
    const validTags = data.dietaryTags.filter(t => VALID_TAGS.has(t));

    for (const tag of validTags) {
      await prisma.providerDietaryTag.upsert({
        where: { providerId_tag: { providerId: provider.id, tag: tag as any } },
        update: {},
        create: { providerId: provider.id, tag: tag as any },
      });
    }
  }
}
```

9. **Error handling and retry logic:**
- Wrap each provider's API call + DB update in try/catch
- On API failure (non-200): log error, add to failed list, continue to next provider
- On JSON parse failure: log raw response, add to failed list, continue
- On DB update failure: log error, add to failed list, continue
- NEVER let one provider's failure stop the entire batch
- At the end, if there are failures, print them so the script can be re-run (idempotent)

10. **CLI arguments for flexibility:**
- `--dry-run`: Research providers but don't write to DB (print what would be written)
- `--slug=X`: Process only a single provider by slug (for testing)
- `--limit=N`: Process only the first N providers (for testing)
- `--skip-existing`: Skip providers that already have shortDescription (the 18 hand-crafted ones). DEFAULT behavior.
- `--include-existing`: Also process hand-crafted providers to fill any null fields they may have.

Parse these from `process.argv`.

```typescript
async function main() {
  const args = process.argv.slice(2);
  const dryRun = args.includes("--dry-run");
  const includeExisting = args.includes("--include-existing");
  const slugArg = args.find(a => a.startsWith("--slug="))?.split("=")[1];
  const limitArg = args.find(a => a.startsWith("--limit="))?.split("=")[1];

  // Query providers needing enrichment
  let providers;
  if (slugArg) {
    providers = await prisma.provider.findMany({
      where: { slug: slugArg, status: { not: "DISCONTINUED" } },
      include: { dietaryTags: true },
    });
  } else {
    providers = await prisma.provider.findMany({
      where: { status: { not: "DISCONTINUED" } },
      include: { dietaryTags: true },
      orderBy: { slug: "asc" },
    });
  }

  // Filter to providers needing enrichment
  if (!includeExisting) {
    providers = providers.filter(p =>
      p.description.includes("see research notes") ||
      !p.shortDescription ||
      !p.prosJson ||
      !p.consJson ||
      !p.valueTier
    );
  }

  if (limitArg) {
    providers = providers.slice(0, parseInt(limitArg, 10));
  }

  console.log(`\n=== Phase 24: Bulk Content Enrichment ===`);
  console.log(`Providers to process: ${providers.length}`);
  console.log(`Mode: ${dryRun ? "DRY RUN" : "LIVE"}\n`);

  let enriched = 0, skipped = 0, failed = 0;
  const failedSlugs: string[] = [];
  const BATCH_SIZE = 10;

  for (let i = 0; i < providers.length; i++) {
    const provider = providers[i];
    // ... process each provider
    // Wait 2 seconds between API calls
    if (i < providers.length - 1) {
      await new Promise(resolve => setTimeout(resolve, 2000));
    }
    // Extra pause every BATCH_SIZE providers
    if ((i + 1) % BATCH_SIZE === 0 && i < providers.length - 1) {
      console.log(`\n--- Batch pause (${i + 1}/${providers.length} done) ---\n`);
      await new Promise(resolve => setTimeout(resolve, 5000));
    }
  }

  // Print summary
  console.log(`\n=== Enrichment Complete ===`);
  console.log(`Enriched: ${enriched}`);
  console.log(`Skipped: ${skipped}`);
  console.log(`Failed: ${failed}`);
  if (failedSlugs.length > 0) {
    console.log(`\nFailed slugs (re-run with --slug=X):`);
    failedSlugs.forEach(s => console.log(`  ${s}`));
  }
}

main()
  .catch(console.error)
  .finally(() => prisma.$disconnect());
```
