**File 1: `prisma/seed-data/helpers.ts`**

Contains:
1. `dollarsToCents(dollars: number): number` -- converts dollar amounts to integer cents via `Math.round(dollars * 100)`
2. `recalculateProviderPricing(prisma: PrismaClient, providerId: string): Promise<void>` -- queries all active plans for a provider, calculates min/max pricePerServingCents, checks if any plan has shippingCostCents === 0, then updates the provider's `minPricePerServingCents`, `maxPricePerServingCents`, and `freeShipping` fields.

The PrismaClient import must be: `import type { PrismaClient } from '../../src/generated/prisma/client';`

The recalculation logic:
```typescript
const plans = await prisma.plan.findMany({
  where: { providerId, active: true, pricePerServingCents: { not: null } },
  select: { pricePerServingCents: true, shippingCostCents: true },
});

const prices = plans
  .map((p) => p.pricePerServingCents)
  .filter((p): p is number => p !== null);

const hasFreeShipping = plans.some((p) => p.shippingCostCents === 0);

await prisma.provider.update({
  where: { id: providerId },
  data: {
    minPricePerServingCents: prices.length ? Math.min(...prices) : null,
    maxPricePerServingCents: prices.length ? Math.max(...prices) : null,
    freeShipping: hasFreeShipping,
  },
});
```
