**Function 1: `getProvidersByCategory`**
Signature: `cache(async (options: { category: CategoryType; dietaryTags?: DietaryTag[]; minPrice?: number; maxPrice?: number; minRating?: number; sortBy?: 'rating' | 'price-asc' | 'price-desc' | 'reviews' | 'newest'; page?: number; pageSize?: number; }) => ...)`

- Default `sortBy = 'rating'`, `page = 1`, `pageSize = 12`
- WHERE clause: `active: true` AND `OR: [{ category }, { secondaryCategory: category }]`
- Apply optional filters: `minPricePerServingCents: { gte: minPrice }`, `maxPricePerServingCents: { lte: maxPrice }`, `averageRating: { gte: minRating }`, `dietaryTags: { some: { tag: { in: dietaryTags } } }`
- ORDER BY mapping: `'rating'` -> `{ averageRating: 'desc' }`, `'price-asc'` -> `{ minPricePerServingCents: 'asc' }`, `'price-desc'` -> `{ maxPricePerServingCents: 'desc' }`, `'reviews'` -> `{ reviewCount: 'desc' }`, `'newest'` -> `{ createdAt: 'desc' }`
- Use `Promise.all([prisma.provider.findMany(...), prisma.provider.count({ where })])` for parallel data + count
- Include: `dietaryTags: true`, `plans: { where: { active: true, featured: true }, take: 1 }`
- Pagination: `skip: (page - 1) * pageSize`, `take: pageSize`
- Return type: `{ providers, total, page, pageSize }`

**Function 2: `getProviderBySlug`**
Signature: `cache(async (slug: string) => ...)`
- `prisma.provider.findUnique({ where: { slug } })`
- Include: `plans: { where: { active: true }, orderBy: { sortOrder: 'asc' } }`, `dietaryTags: true`, `faqs: { orderBy: { sortOrder: 'asc' } }`, `reviews: { where: { status: 'APPROVED' }, orderBy: [{ helpful: 'desc' }, { createdAt: 'desc' }], take: 10 }`
- Return the provider or null

**Function 3: `getProvidersForComparison`**
Signature: `cache(async (slugs: string[]) => ...)`
- `prisma.provider.findMany({ where: { slug: { in: slugs }, active: true } })`
- Include: `plans: { where: { active: true }, orderBy: { sortOrder: 'asc' } }`, `dietaryTags: true`
- Return array of providers

**Function 4: `getFeaturedProviders`**
Signature: `cache(async () => ...)`
- `prisma.provider.findMany({ where: { active: true, featured: true } })`
- Include: `dietaryTags: true`
- OrderBy: `{ averageRating: 'desc' }`
- Take: 8
- Return array of providers

**Function 5: `getCategoryCounts`**
Signature: `cache(async () => ...)`
- `prisma.provider.groupBy({ by: ['category'], where: { active: true }, _count: true })`
- Return the grouped counts array

**Function 6: `searchProviders`**
Signature: `cache(async (query: string) => ...)`
- `prisma.provider.findMany({ where: { active: true, OR: [{ name: { contains: query, mode: 'insensitive' } }, { description: { contains: query, mode: 'insensitive' } }] } })`
- Include: `dietaryTags: true`
- Take: 20
- Return array of providers

**Function 7: `getAllProviderSlugs`**
Signature: `cache(async () => ...)`
- `prisma.provider.findMany({ where: { active: true }, select: { slug: true } })`
- Return array of `{ slug: string }`

**Function 8: `getRelatedProviders`**
Signature: `cache(async (slug: string, category: CategoryType, limit: number = 4) => ...)`
- `prisma.provider.findMany({ where: { active: true, slug: { not: slug }, OR: [{ category }, { secondaryCategory: category }] } })`
- OrderBy: `{ averageRating: 'desc' }`
- Include: `dietaryTags: true`
- Take: `limit`
- Return array of providers

**Function 9: `getAdminStats`**
Signature: `cache(async () => ...)`
- Use `Promise.all` to query in parallel:
  - `prisma.provider.count()`
  - `prisma.review.count()`
  - `prisma.review.count({ where: { status: 'PENDING' } })`
  - `prisma.affiliateClick.count()`
- Return: `{ providerCount, reviewCount, pendingReviewCount, affiliateClickCount }`

**Function 10: `getProviderReviewStats`**
Signature: `cache(async (providerId: string) => ...)`
- `prisma.review.groupBy({ by: ['rating'], where: { providerId, status: 'APPROVED' }, _count: true })`
- Return the grouped array for building rating breakdown charts

All functions use named `export const` pattern (not `export function`), e.g.:

  ...
});
