    **src/components/RatingStars.tsx** (per D-11):

    Props:
    - `rating: number` (0-5, supports decimals like 4.3)
    - `showNumeric?: boolean` (default: `true` -- shows "4.3" text next to stars)
    - `size?: "sm" | "md" | "lg"` (default: `"md"`)
    - `className?: string`

    Size map for star SVG dimensions and text size:
    ```
    const sizeMap = {
      sm: { width: 16, height: 16, textClass: "text-xs" },
      md: { width: 20, height: 20, textClass: "text-sm" },
      lg: { width: 24, height: 24, textClass: "text-base" },
    } as const;
    ```

    Star type logic:
    - Create an array of 5 types: `Array.from({ length: 5 }, (_, i) => { const fill = rating - i; if (fill >= 0.75) return "full"; if (fill >= 0.25) return "half"; return "empty"; })`
    - This means 4.3 renders as 4 full + 1 half; 4.1 renders as 4 full + 1 empty; 4.7 renders as 5 full

    Internal `StarIcon` function (NOT exported, defined inside the file):
    - Props: `{ type: "full" | "half" | "empty"; width: number; height: number; index: number }`
    - SVG element: `<svg viewBox="0 0 24 24" width={width} height={height} xmlns="http://www.w3.org/2000/svg">`
    - Star path: `"M12 2l3.09 6.26L22 9.27l-5 4.87 1.18 6.88L12 17.77l-6.18 3.25L7 14.14 2 9.27l6.91-1.01L12 2z"`

    For `"full"` star:
    - `<path d={starPath} className="fill-star stroke-star" strokeWidth={1} />`

    For `"empty"` star:
    - `<path d={starPath} className="fill-star-empty stroke-star-empty" strokeWidth={1} />`

    For `"half"` star:
    - Use SVG `<defs>` with a `<linearGradient>` to fill exactly 50%:
      ```
      <defs>
        <linearGradient id={`half-grad-${index}`} x1="0%" y1="0%" x2="100%" y2="0%">
          <stop offset="50%" style={{ stopColor: "var(--color-star)" }} />
          <stop offset="50%" style={{ stopColor: "var(--color-star-empty)" }} />
        </linearGradient>
      </defs>
      <path d={starPath} fill={`url(#half-grad-${index})`} className="stroke-star" strokeWidth={1} />
      ```
    - The `index` prop (0-4) ensures unique gradient IDs per star within a single RatingStars instance. For page-level uniqueness across multiple RatingStars, the gradient IDs only need to be unique within their SVG element (each star is its own SVG), so `half-grad-${index}` is sufficient.

    Outer container:
    - `<div className={`flex items-center gap-0.5 ${className ?? ""}`} role="img" aria-label={`Rating: ${rating.toFixed(1)} out of 5 stars`}>`
    - Map stars array: `stars.map((type, i) => <StarIcon key={i} type={type} width={sizeMap[size].width} height={sizeMap[size].height} index={i} />)`
    - After stars, if `showNumeric`: `<span className={`ml-1.5 font-medium text-gray-700 ${sizeMap[size].textClass}`}>{rating.toFixed(1)}</span>`

    Export as default.
