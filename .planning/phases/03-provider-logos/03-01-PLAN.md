  <action>
Create `src/components/ProviderLogo.tsx` as a Server Component (no "use client") following established patterns from Badge.tsx and Button.tsx.

**Props interface:**
```typescript
Readonly<{
  logoUrl: string | null;
  name: string;
  size?: "sm" | "md" | "lg";
  className?: string;
  priority?: boolean;
}>
```

**Size map** (as const object, same pattern as Button.tsx sizes):
```typescript
const sizes = {
  sm: { container: "w-10 h-10", image: 40, text: "text-sm" },
  md: { container: "w-16 h-16", image: 64, text: "text-xl" },
  lg: { container: "w-48 h-48", image: 192, text: "text-4xl" },
} as const;
```

**Rendering logic:**
- When `logoUrl` is non-null: Render Next.js `<Image>` with `width` and `height` from the size map, `alt="{name} logo"`, `className="object-contain"`, and pass through `priority` prop. Wrap in a container div with the size map's container classes plus `rounded-xl bg-gray-50 border border-gray-100 flex items-center justify-center overflow-hidden`.
- When `logoUrl` is null: Render the same container div but with the provider's first initial (`name.charAt(0).toUpperCase()`) in a `<span>` using `font-bold text-gray-300` and the size map's text class.
- Append `className` prop to the outer container div (use `${className ?? ""}` pattern).

**Image padding by size:**
- sm: `p-1`
- md: `p-1`
- lg: `p-4`

**Do NOT** add "use client" — this is a pure presentational Server Component.
**Do NOT** add error/loading states — Next.js Image handles those.

Default export: `export default function ProviderLogo(...)`.
