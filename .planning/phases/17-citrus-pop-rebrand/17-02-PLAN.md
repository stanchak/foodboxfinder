# Plan 17-02: Bulk Color Class Replacement

## Objective

Replace all hardcoded Tailwind `gray-*` classes with `neutral-*` across the entire codebase, and fix `emerald-*` references to use `primary-*`. This ensures all components use the design system's warm-tinted neutral tokens rather than Tailwind's default cool grays.

## Tasks

### Task 1: Bulk replace gray→neutral in all .tsx files under src/

Systematic find-and-replace across all .tsx files in src/components/ and src/app/:

- `text-gray-` → `text-neutral-`
- `bg-gray-` → `bg-neutral-`
- `border-gray-` → `border-neutral-`
- `ring-gray-` → `ring-neutral-`
- `divide-gray-` → `divide-neutral-`
- `from-gray-` → `from-neutral-`
- `to-gray-` → `to-neutral-`
- `via-gray-` → `via-neutral-`
- `hover:bg-gray-` → `hover:bg-neutral-`
- `hover:text-gray-` → `hover:text-neutral-`
- `placeholder:text-gray-` → `placeholder:text-neutral-`
- `disabled:bg-gray-` → `disabled:bg-neutral-`
- `disabled:text-gray-` → `disabled:text-neutral-`
- `outline-gray-` → `outline-neutral-`
- `shadow-gray-` → `shadow-neutral-`

**PRESERVE:** Do not touch files in src/generated/. Do not change semantic color classes (green-*, red-*, amber-*, blue-*, yellow-*). Do not change `bg-white` or `text-white`.

### Task 2: Fix emerald→primary in error and not-found pages

In src/app/error.tsx and src/app/not-found.tsx:
- Replace `emerald-*` classes with `primary-*` equivalents
- e.g., `bg-emerald-600` → `bg-primary-600`, `text-emerald-600` → `text-primary-600`, etc.

## Files Modified
- All .tsx files in src/components/ (~25 files)
- All .tsx files in src/app/ (~30 files, excluding src/app/admin/)
- src/app/error.tsx
- src/app/not-found.tsx
